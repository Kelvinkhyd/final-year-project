# UA-Shop Frontend — Premium Edition

## Setup
```bash
npm install
npm run dev
```
Opens at http://localhost:5173
Make sure the backend is running on http://localhost:5000 first.

## Pages
- Home — Hero, UA pillars, demo identities
- Shop — Product grid with category filter and cart
- Register — UA-compliant registration / My Account
- Cart — Order placement with confirmation screen
- Orders — Order history
- Admin Dashboard — Live UAVE tester, BiDi panel, users table
